From manual geometry to automatic matching

Both use the same custom homography warping and feather blending. The results are useful registrations with documented geometric limitations.

01 / OVERVIEW

Introduction

This project estimates homographies from manually matched features, inverse-warps images with custom nearest-neighbor and bilinear sampling, and combines valid pixels with feather weights. Real experiments include two rectifications, three planar mosaics, and a cylindrical panorama.

Image coordinates are (x = column, y = row), with upper-left pixel center (0,0). EXIF orientation is applied in memory before selecting points. Matrices act on column vectors and map source to destination. All original JPEGs are preserved.

Publication images are regenerated from the original photographs and accepted experimental outputs. Original JPEGs and numerical results remain unchanged. All scales and dimensions below describe the actual experiments.

03 / GEOMETRY

A.2 · Recover homographies

A planar homography has eight independent coefficients after fixing h33=1. For a source feature (x,y) and its match (u,v):

(1) Source-to-target homogeneous mapping

[u,v,1]ᵀ ∼ H [x,y,1]ᵀ
H = [[h11,h12,h13], [h21,h22,h23], [h31,h32,1]]
u=(h11*x+h12*y+h13)/(h31*x+h32*y+1)
v=(h21*x+h22*y+h23)/(h31*x+h32*y+1)

(2) Explicit least-squares system

h = [h11,h12,h13,h21,h22,h23,h31,h32]ᵀ
A[2i]   = [x, y, 1, 0, 0, 0, -u*x, -u*y]
A[2i+1] = [0, 0, 0, x, y, 1, -v*x, -v*y]
b[2i]=u; b[2i+1]=v
A ∈ ℝ^(2N×8); A h = b
numpy.linalg.lstsq(A, b, rcond=None)

The custom computeH uses float64 least squares and rejects nonfinite, rank-deficient or singular solutions. With more than four pairs, the system is overdetermined. It minimizes algebraic error; coordinates are not normalized and no RANSAC or automatic matching is used.

05 / SAMPLING

A.3 · Warp the images

Inverse warping visits each destination pixel center, applies H⁻¹, divides by the homogeneous coordinate, and samples the source. This avoids forward-splatting holes inside valid source support.

(3) Inverse coordinates

[a,b,c]ᵀ = H⁻¹ [x_d,y_d,1]ᵀ
s_x=a/c; s_y=b/c
x_d=xmin+column; y_d=ymin+row

Nearest neighbor reads (floor(sx+0.5), floor(sy+0.5)). Bilinear interpolation weights the four source neighbors manually:

(4) Bilinear intensity

x0=floor(s_x); y0=floor(s_y)
α=s_x-x0; β=s_y-y0
I=(1-α)(1-β)I[y0,x0] + α(1-β)I[y0,x1]
 + (1-α)β I[y1,x0] + αβ I[y1,x1]

At the last row/column, the repeated boundary neighbor preserves the sample value. Finite inverse coordinates must lie within source pixel-center bounds; other samples remain invalid in a separate mask. Canvas origins preserve negative destination coordinates. The implementation rejects singular transforms, horizon crossings and unsafe allocations.

07 / PLANAR COMPOSITION

A.4 · Blend images into mosaics

Each accepted scene uses two photographs, with its central view as reference and identity H. The other direct H maps into that reference. Existing custom bilinear inverse warps populate a common canvas with boolean validity masks. Dark photographed pixels remain valid; RGB intensity is not a validity test.

(5) Distance feathering

d_i(p)=distance to nearest invalid mask sample
w_i(p)=d_i(p)/Σ_j d_j(p), if Σ_j d_j(p)>0
I_out(p)=Σ_i w_i(p) I_i(p)
M_union(p)=[Σ_j d_j(p)>0]

A SciPy Euclidean distance transform supplies mask distances, including an invalid padding ring. Weights sum to one on the valid union. Each source contributes both overlap and exclusive new pixels. Full registered footprints are retained privately; the displayed frames below are documented reference-coordinate crops made after registration and blending, not the full footprints.

Hallway · left + center

Molding and the exit doorway remain coherent. The left door expands under the planar projection; local foreground parallax and softness remain. The tighter frame preserves new content from both images without claiming the three-image footprint is distortion-free.

Gateway exterior · center + right

Architectural lines are broadly coherent. Trees and the far-right façade are softer and somewhat stretched. The failed left-to-center alignment is excluded rather than presented as a successful three-frame stitch.

08 / CS 280A EXTENSION

A.5 · Cylindrical projection

The accepted nonplanar result uses the same atrium 03+04 photographs. Each source is projected directly from its orientation-corrected working photograph, not by bending a planar mosaic. The centered mapping and inverse are:

(6) Forward cylindrical map

c_x=(width−1)/2; c_y=(height−1)/2
u=f atan((x−c_x)/f)
v=(y−c_y) f/√((x−c_x)²+f²)

(7) Inverse cylindrical sampling

θ=u/f; |θ|<π/2
x=c_x+f tan(θ)
y=v/cos(θ) + c_y

Output pixels use this inverse and the existing manual bilinear sampler. Invalid samples have mask false. Sources are downscaled once before projection; f scales by the same factor. Projection origins are shifted by integer global translations, without resampling the projected images again.

(8) Manual translation registration

Δ_source→target = median_i(C(p_target,i)−C(p_source,i))
O_03=(0,0); O_04=Δ_04→03
I_cyl=feather_blend(shift(C(I_i), O_i))

The median is computed componentwise from all ten confirmed 04→03 pairs, without filtering. Rounded working offsets differ by at most 0.5 px per axis. Median/mean/maximum residuals are 25.86/46.21/132.90 original-resolution cylindrical pixels, not planar residuals or preview-sized values. Translation is approximate because capture is not calibrated pure yaw.

EXIF records 5.96 mm focal length and 26 mm full-frame equivalent. Sensor/crop/stabilization calibration is unavailable, so these are rough starting clues. The selected f=5400 px is an empirical registration/visual choice, not verified camera calibration. Its single-image horizontal field of view is 55.74° in this model.

Cylindrical projection reduces peripheral planar stretching and keeps the panorama bounded. Horizontal lines may curve on the cylinder; vertical architectural structure is generally better preserved here. Some railing misalignment and moving-person ghosts remain. Five-frame and central-three cylindrical attempts rendered but were rejected as primary evidence because of stronger doubled stairs/railings and cumulative drift. Only two sources are claimed in the accepted result.

09 / LIMITATIONS

Limitations

Unnormalized algebraic least squares is sensitive to coordinate scale and incorrect matches. Planar homographies cannot align multiple depths under camera translation, and wide fields can cross their projective horizon. Feathering cannot remove parallax, moving subjects or exposure changes. Cylindrical translation assumes approximately compatible viewing directions and a centered principal point; an empirical focal length is not a camera calibration.

10 / CONCLUSIONS

Implementation and conclusions

Custom homography estimation and inverse sampling support both rectifications and the three real planar scenes. The nearest/bilinear comparison demonstrates a measured speed–smoothness tradeoff. Narrower planar subsets and explicit display framing avoid overstating success on wider captures. Cylindrical projection provides a different wide-view geometry, while its residuals and visible ghosts make the registration limitations clear.

Numerical validation: 216 regression tests passed after the A.5 experiment, with further report-asset checks performed during preparation. NumPy handles the linear solve; Pillow handles image I/O and derivative resizing; Matplotlib provides figures; SciPy is used only for the feather distance transform. No high-level library homography, warp or stitcher replaces the custom implementations.

PART B / AUTOMATIC CORRESPONDENCES

B.1 · Harris corners and ANMS

Harris corners supply repeatable intensity changes in two directions. The reviewed Berkeley Harris starter motivates the scikit-image corner_harris(method="eps") adapter: sigma 1, relative response threshold 0.01, minimum peak separation 1 and strict 20-pixel border exclusion. Images use EXIF-corrected orientation and Rec.709 luminance. Coordinates are (x=column, y=row).

Adaptive non-maximal suppression (ANMS) retains spatially isolated strong candidates. For corner i, its radius is the distance to the nearest candidate j satisfying the strict robust condition below. No qualifying neighbor gives infinite radius. Select 500 by decreasing radius, breaking ties by strength and then y/x. This is feature selection, not matching.

(B1) Robust suppression, c=0.9

r_i = min_j ||p_i − p_j||, where f_i < 0.9 f_j and j ≠ i

The source photographs are retained in Figures 1–3. Here the raw and selected overlays use the same pixels, making the selection effect visible.

PART B / PATCH REPRESENTATION

B.2 · Normalized feature descriptors

Each selected corner uses a nominal 40×40 native-pixel neighborhood. Gaussian blur with sigma 2 (reflect boundaries, truncate 4) precedes bilinear sampling of an 8×8 grid at five-pixel spacing. Offsets are −17.5, −12.5, …, 17.5 in both axes. Flatten row-major into 64 float64 values, subtract the patch mean and divide by population standard deviation. Reject out-of-bounds support and standard deviation ≤10⁻⁸.

(B2) Patch normalization

D = (P − mean(P)) / std(P), ddof=0

All six photographs produced 500 valid descriptors from 500 selected locations. This MOPS-style baseline is axis-aligned; it does not claim rotation invariance or the complete oriented/wavelet MOPS pipeline. No SIFT or ORB replaces the patch implementation.

PART B / DESCRIPTOR SEARCH

B.3 · Automatic feature matching

For every source descriptor, find the nearest and second-nearest destination rows by Euclidean distance. Accept strictly when d₁/d₂ < 0.80. The threshold is an experimental default. A zero second-neighbor distance is ambiguous and rejected. Matching is directional, with no mutual or unique-target filter; several sources can choose one destination.

The accepted pre-RANSAC counts are 129 hallway, 47 exterior and 82 atrium. A threshold sweep from 0.60 to 0.90 yielded 55–212, 12–119 and 48–144 matches respectively. More permissive matching supplies more candidates, not proven geometric accuracy. Repeated windows, rails and non-overlap content remain ambiguous.

PART B / ROBUST GEOMETRY

B.4 · Four-point RANSAC and automatic mosaics

Sample four candidate pairs, estimate source-to-reference H using the custom eight-unknown linear solve, project every source candidate and count errors strictly below 4 working-image pixels. Keep the best consensus and refit using its inliers, then reclassify. Degenerate samples are rejected. All scenes use seed 2804 and 5000 trials; no manual points or manual H guide fitting.

(B3) Forward reprojection error

q̂_i = dehomogenize(H [x_i, y_i, 1]ᵀ)
e_i = ||q̂_i − q_i||₂; inlier ⇔ e_i < 4 working pixels

Build three Gaussian pyramid levels directly from the same base working luminance image at nominal scales 1.00, 0.75 and 0.50. For actual ratio s on each axis, prefilter sigma is 0.5√(s⁻²−1), using reflect boundaries and truncate 4, then bilinearly sample at half-pixel resize centers. Level zero is an exact luminance copy. Harris, ANMS and descriptor extraction run independently on each level's actual image signal.

Descriptors retain the same native 40×40 support, so coarse levels describe larger physical regions. Store native coordinates and level IDs, then convert once before matching geometry:

(B4) Half-pixel level-to-base mapping

s_x = W_level / W_base; s_y = H_level / H_base
x_base = (x_level + 0.5) / s_x − 0.5
y_base = (y_level + 0.5) / s_y − 0.5

Actual rounded dimensions determine these ratios. All RANSAC thresholds and homographies use base working-image pixels. Cross-level descriptor matches are allowed, using the unchanged Euclidean ratio <0.80, seed 2804, 5000 trials and 4-pixel threshold.

Primary deduplication keeps finer features first, preserving ANMS order within a level, and suppresses coarser features within 3 base pixels. It never compares Harris responses between scales. This removed many coarse features; realized totals are substantially below 500. Hallway center had only 112 coarse candidates, leaving 13 unused slots even before suppression.

COMBINED / TAKEAWAYS

Manual, automatic and multiscale

Automatic correspondence selection recovers useful homographies from these real photographs. RANSAC removes many incorrect patch matches, while manual and automatic pipelines share warping and blending. Accurate projected points do not make a multi-depth scene planar. Architectural repetition, foreground extrapolation and moving people remain visible failure modes. The multiscale extension is operational, with mixed or negative findings under these defaults.

Implementation and reproducibility

The private implementation contains Harris detection, robust ANMS, normalized MOPS-style patches, directional Lowe matching, custom four-point RANSAC and multiscale wrappers. Source code is submitted privately through Gradescope; this static website contains only report text, CSS and reviewed PNG derivatives. No private source repository is linked.

The B7 implementation regression result was 430 passing tests, zero failures or skips. The original Part A validation paragraph describes its historical environment and scope; Part B additionally uses SciPy Gaussian filtering and the reviewed scikit-image Harris adapter. Independent synthetic tests cover reprojection, sampling, feature provenance and coordinate conversions. These validate numerical behavior, not the absence of photographic seams.
